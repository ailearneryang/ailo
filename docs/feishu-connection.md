# 飞书应用连接（0.1.43）

入口：扩展 → 应用连接 → 点击飞书卡片或“＋”，自动打开浏览器授权，不经过介绍弹窗。授权状态、重开授权页和取消操作显示在卡片上；已连接后点击卡片管理权限或解绑。安装官方 lark-cli 后，在浏览器完成应用配置和用户授权。连接成功后点击“去试试”，或直接在对话中提出飞书需求。

本版参考 WorkBuddy 的 CLI 连接流程：检测安装、检查授权、打开授权页、轮询状态、对话调用、解绑。使用独立的 ailo-desktop CLI 配置；凭证由 CLI 管理，不进入模型上下文。解绑关闭 Ailo 调用并注销此配置的本机用户登录，服务端授权需在飞书授权管理中撤销。

Agent 可查询接口 schema 后调用授权范围内的飞书业务 API。常用文档搜索、读取、创建和文字消息发送另提供受控快捷入口及参数帮助。发送、修改、删除操作展示完整参数供用户确认；未知结果不会自动重复提交。读到的外部内容不构成发送授权。文件上传下载和媒体消息不在本版快捷入口范围内，不能理解为飞书全产品能力已逐一验证。

点击“补充权限”可根据缺失 scope 提示发起新增授权，仍受企业应用审批、资源访问权及用户权限约束。旧版自建应用 App ID/Secret 文档导入保留在高级选项，与 CLI 登录独立。

验证：连接管理、固定命令参数、凭证脱敏、写操作确认、重启后重复提交保护、快捷命令校验和 Agent 对话调用均有模拟测试。已对本机 lark-cli 1.0.39 做版本与帮助命令检查。未登录真实账号，未向飞书发送消息；真实授权及业务 API 需连接后联调。
