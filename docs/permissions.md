# 操作权限

输入框中的“操作权限”可为当前对话选择模式；用户菜单 → 设置 → 操作权限可管理默认模式和已授予的范围。

## 模式与范围

- **标准权限（默认）**：已打开项目内可以读取、编辑并执行本地命令；扩大访问范围时询问用户。不会自动复用持续授权。
- **按范围授权**：复用用户明确授予的范围，未获授权的操作仍需批准。

批准可选择仅本次、本任务或持续允许，具体选项取决于操作能否安全复用。本任务授权只在当前应用会话内有效，不传递给其他任务。持续授权按本机账号隔离，只有按范围模式可以复用。任务开始执行时固定其模式，执行中不能切换。

## 实际执行边界

项目命令通过 macOS sandbox-exec 执行，默认禁止网络访问。Agent 使用 request_network 说明用途，经用户批准后才可联网；联网许可绑定当前项目及其真实目录，不扩大文件访问范围。

外部目录使用系统文件夹选择器，并进行独立的授权确认。目前仅支持只读访问及其子目录，真实路径与目录身份会在执行命令前重新检查。需要修改外部文件时，应将文件夹打开为本地项目。

应用仍须已连接并通过既有工具权限检查。可复用的 MCP 操作批准匹配同一项目、连接及工具定义指纹和完全相同的参数；连接或工具定义变化后重新批准。没有稳定定义指纹的应用写操作每次确认。原有幂等记录继续负责防止重复提交。

此功能不提供完全访问权限，不绕过操作系统权限，也不把模型自身的风险判断作为唯一批准依据。

## 管理与撤销

权限中心支持添加只读目录、按类型筛选、查看来源任务、撤销单项或全部授权，以及查看最近的授权记录。撤销会中止正在使用相关授权的执行；已经完成的文件更改和外部操作不会自动撤回。撤销期间尚未完成的批准不能重新创建已失效的许可。

权限保存在应用数据目录下 permissions/ 中，文件名使用账号散列，写入采用原子替换与 0600 权限。记录保留授权范围、时间及操作参数的签名，不保存应用操作正文。最近审计记录上限为 150 条。

## 验证

scripts/permissions.test.cjs 覆盖账号与任务隔离、参数指纹、目录替换、运行中模式锁定、拒绝及撤销竞态。
scripts/permissions-sandbox.test.cjs 在真实 macOS 沙箱内检查联网限制、外部目录写入拒绝及撤销终止命令。
scripts/permissions-smoke.cjs 使用隔离数据启动打包后的桌面应用，检查模式选择、默认模式持久化、目录批准、撤销与窄窗口布局。
