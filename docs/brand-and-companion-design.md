# Ailo 品牌与陪伴角色

Ailo 的角色定位是温暖、可靠的工作伙伴。保留橙色柴犬、奶油色口鼻、深绿色五官和浅薄荷绿领巾；圆润脸颊、短圆耳尖、较低的五官重心、小鼻子与闭口微笑。少量眼神高光、奶油色眉斑和低对比颊色增加亲和力，保持清晰的平面矢量风格。选定 E「清新薄荷」：应用图标与小头像使用 `#DCF0E5` 浅薄荷底，领巾与互动道具使用 `#AED7C3`，细节使用 `#5F8B75`；五官保留深绿以保证清晰。全身角色保持透明。

`apps/desktop/pet-artwork.cjs` 是共同脸型与配色来源。图标、页面头像、全身动画共用头部轮廓、眉斑、眼睛、高光、颊色和口鼻路径，禁止分别重画一套脸。`npm --prefix apps/desktop run icons` 生成 SVG、PNG、favicon 与 ICNS；标准打包自动生成。PNG 直接从矢量按目标尺寸栅格化，避免抠图边缘、透明杂点和多次缩放损耗。

| 场景 | 形态与行为 |
| --- | --- |
| Dock、关于、账号 | 静态浅薄荷底品牌标记；独立于宠物显示偏好 |
| 首页、我的 Ailo、陪伴页 | 全身角色，轻微呼吸和偶尔眨眼；点击有短暂回应 |
| 导航、回复署名 | 简洁头像，默认静态，不持续庆祝或摇动 |
| 实时任务活动 | 头像可表达思考；状态来自真实任务，不改变验收口径 |
| 已完成、需处理 | 表情与不同形状角标共同区分，不只依赖颜色 |

动画不抢正文注意力。完成跳跃与触摸回应为有限次数；切换后台或滚出可见区暂停。关闭动画、安静风格及系统减少动态效果都停止动作，仍保留静态表情与状态含义。隐藏宠物保留中性助手图标；品牌身份仍可识别。所有可点击角色支持键盘与焦点轮廓，自定义名字用于可访问名称。

验证应包含浅深主题、24–36px 头像、首页全身、状态角标、真实点击、离屏暂停与减少动态效果。视觉一致性不等于用户喜欢程度；后续可观察用户是否保留宠物显示、是否主动互动，并结合访谈判断，不通过强提醒或等级惩罚制造使用压力。

整体比例以大头、紧凑坐姿、圆爪与单圈卷尾形成亲切感；领巾使用低饱和薄荷绿和极少量缝线细节。专业感来自统一几何、清楚留白和克制动作；不依赖大幅弹跳、连续粒子或多层装饰。小头像保留简洁的脸部，移除身体和领巾。

摸摸时短暂歪头、轻摇尾和一颗浮起的爱心；喂食时小幅低头与咀嚼，显示浅绿食盆；玩耍时两次轻跳和短暂弹球。小头像不响应全局互动，只保留真实任务状态。完成时仅轻跳一次；完成使用浅绿勾选、待处理使用浅杏色感叹号，以形状与颜色共同区分。安静模式、减少动态效果和离屏暂停覆盖所有互动动作。
