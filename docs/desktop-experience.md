# 桌面工作流与对话管理

这批改造以完整工作流为边界，覆盖对话整理、消息分支、项目资料复用、成果检索、待处理事项、通知、临时对话与语音输入。

## 对话与侧栏

侧栏按置顶、项目和最近对话组织。项目中的对话只在项目下显示；最近对话按今天、昨天和月份分组，默认显示30条，可展开更多。搜索包含已归档对话，不包含临时对话。

对话菜单支持手动重命名、置顶、移动、归档、删除和 Markdown 导出。手动命名不会被模型生成的标题覆盖。归档不删除内容，可通过搜索、设置 → 已归档对话找回并恢复。删除前需要确认；删除仅移除工作空间中的聊天记录，不删除项目文件、已保存记忆、消息编辑备份和外部系统中已经完成的操作，也不承诺物理擦除这些独立数据。

运行或排队中的对话不能移动、归档或删除。移动对话不会复制、覆盖或移动文件；既有交付保留来源项目，可从文件与成果访问。移动会生成新的执行记录身份并清除压缩上下文，避免移回原项目时恢复陈旧操作记录。后续执行使用目标项目的新背景与权限范围。定时任务的项目归属在定时任务设置中管理。

## 消息分支与重新生成

消息操作支持从某条消息创建分支。分支只保留该消息及之前的聊天，并显示原对话入口；不会复制正在执行的计划或批准。

重新生成以最近的用户问题为截止点创建独立分支，保留原对话和后续讨论。首次重新生成仅生成文本回答，可以参考当前项目背景与已启用的记忆，不执行外部工具；完成后，后续新请求恢复正常 Agent 流程。这能避免将已完成的发消息、文件修改等副作用当作生成文本重复执行。

## 项目设置

项目概览 → 项目设置支持项目指令、共享文本资料和新对话默认工具。资料通过现有文件解析器提取文本，每份最多10万字符、每项目最多20份；保存前可预览和移除。模型请求中的项目上下文最多3万字符，单份资料最多注入6000字符，因此较长资料不会被完整送入每轮请求；完整资料检索请使用知识库。

项目指令与资料会实际进入项目 Agent 的模型请求，而不是只保存在设置界面。保存采用设置版本检查，拒绝覆盖并发修改；运行中的项目不能修改设置。普通模型设置保存也不会覆盖项目指令与资料。默认工具不代替账号连接、服务端权限和操作批准。

## 文件与成果

文件与成果汇总交付成果与对话附件，支持文件名/来源搜索、项目、来源、格式、时间范围筛选以及名称和时间排序。每项显示来源对话、大小、登记时间和登记版本。移动、分支后的旧成果仍可定位原文件。

预览复用现有 HTML 隔离、PDF、表格、图片和文本预览能力；全局文件中心为只读视图，可跳到来源对话或在系统文件夹中查看。登记版本不是历史文件内容快照：文件在登记后被修改时，预览会明确显示正在读取磁盘上的最新内容。项目原本的编辑与版本恢复仍在任务侧栏中使用。

## 待处理中心与通知

待处理事项默认折叠为一行摘要。展开后可查看阻塞原因、直接提交澄清答案或重试当前步骤；权限操作只会重新触发已有的批准流程，不会自动代替用户批准。并发回答会在存储事务中检查问题是否仍为最新，避免重复提交。

通知中心统一记录普通、委托和定时任务完成、失败与等待处理的结果，按请求与状态去重。支持全部已读和分类开关。系统通知默认关闭，可在通知设置中启用；后台通知不携带聊天正文，点击可返回来源任务。通知记录及设置按本机账号隔离，临时对话不会生成通知。

工具菜单根据连接器状态显示已启用、已连接但未启用、未连接、检查失败或连接异常。图标组表示当前选择，不保证服务在线。

## 临时对话

新对话右上角可启动临时对话。当前版本提供无记忆、无工具、无项目上下文的文本交流，也支持离线听写回填。临时内容仅保存在主进程内存中；聊天、压缩上下文、模型诊断和用量记录不写入本地工作空间。不能添加附件、创建分支或导出。离开当前临时对话、刷新页面、窗口关闭、渲染进程崩溃、账号切换和退出应用时清理并取消请求。已结束的临时ID不能被迟到的请求恢复。

临时对话不等于模型服务商不留存：请求仍发送到用户选择的模型接口，服务商的保留规则需要单独了解。

## 语音输入

macOS 原生 Speech/AVFoundation 组件提供中英文听写。首次使用需要麦克风和语音识别权限，并要求系统支持所选语言的离线识别；不支持时返回明确错误，不自动改用网络识别。采用 requiresOnDeviceRecognition=true，且先检查 supportsOnDeviceRecognition。最长60秒，支持停止、取消和流式转写；结果先放入输入框供修改，绝不自动发送。音频不写入文件。切换对话、关闭窗口或退出时停止采集。

构建脚本将原生组件编译后随 Electron 应用打包，并配置麦克风与语音识别用途说明。自动测试覆盖进程取消、事件分片和转写回填；没有使用用户麦克风进行真实识别准确率测试，实际可用性取决于系统权限、语言资源及音频设备。

- task-notifications.test.cjs：去重、开关、账号隔离和临时对话排除。
- dictation.test.cjs：流式转写、停止、取消、并发启动拒绝。
- experience-smoke.cjs：真实打包应用的重命名/归档/恢复/搜索、分支生成、移动、待处理直接回答、项目资料进入模型请求、文件预览、通知、临时对话、模拟语音IPC回填和删除。

## 状态展示的一致性

侧栏、当前进度卡及输入框活动使用同一份请求状态解释。活动会话包含当前输入ID、阶段、意图和执行快照；请求仍存在不再直接等同于任务正在执行。新一轮提问不会继承旧计划的暂停/失败状态。此前计划以“此前任务进度”标识，在本轮回复中禁用继续操作；真正恢复任务后才作为当前计划显示。

轮询与推送合并时保留已结束请求ID，避免迟到快照恢复已经结束的会话。活动说明及进展时间只参考当前请求开始后的事件，旧计划的时间不会显示成当前回复进展。
