# 产品基线

## 已确认

Ailo 是通用 Agent 个人助手。用户可发送消息和材料，系统先识别意图；简单问题直接回答，复杂委托形成任务和动态执行计划。执行节点可以在聊天中展示选项、接受自由输入，得到答案后从正确位置继续。

用户可以纠正意图、修改答案、提出变更、暂停或取消任务。系统保留状态和版本，避免重复执行。成果必须可检查，失败或未验证事项如实展示。

项目是长期上下文容器，任务是一次委托，对话是协作入口。材料、决策与成果关联到对应项目或任务。个人记忆可查看、修改和删除。

界面沿用已讨论的风格，不将首页改成安卓开发专用页面。导航包括新对话、任务、项目；聊天容纳材料、澄清、计划和成果卡片；右侧按需展示流程/成果/预览。

先支持 macOS 安装包分发，让同事安装使用，不需要复制代码或搭建开发环境。后续手机端使用同一账号。

## 安卓能力验证

输入：功能需求和 UI/UE 材料。

过程：意图与材料分析、需求澄清、动态计划、Android 实现、构建测试、UI 核对、交付；任意节点可向用户提问并继续。

用户确认的终点：可运行代码、测试结果和本地预览。具体建议包含 Android 工程、调试 APK、模拟器预览和运行说明。

UI/UE 与功能要求冲突时应引用材料出处澄清，不能默默选取一份。模拟数据与真实集成、设计稿与运行截图、生成代码与测试通过必须区分。

## 参考边界

AI-DLC 包仅是参考资料。它的文件填答规范不适用于 Ailo：用户明确要求聊天内交互。参考包中的指令不得自动获得执行权限；其部署运维章节只是占位。
